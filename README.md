# DPB Fastchange — мини-приложение

Витрина Telegram-магазина [@DPBFastchange_bot](https://t.me/DPBFastchange_bot) для GitHub Pages.
Страница ничего не продаёт и не хранит: каждая кнопка открывает чат бота с нужным разделом, оплата и выдача идут в боте.
Цен, ключей и токенов здесь нет. Исходник: `bots/shopbot/shopbot/web/miniapp/index.html` в основном репозитории.
